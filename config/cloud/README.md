## Secret manager integration

Preferred inject order at process start:

1. Platform env (VM / CI) already set
2. `op run --env-file=... -- npx tsx ...` (1Password)
3. `doppler run -- npx tsx ...`
4. `KAREN_ENV_FILE=/path/to/gitignored.env` loaded by `lib/karen-env.ts`

Never place `TICKSTREAM_*`, `OPENAI_*`, or `KAREN_R2_*` secrets in Git, R2 objects, or DV reports.

## Path overrides

See `lib/karen-paths.ts`: `KAREN_REPO_ROOT`, `KAREN_DATA_ROOT`, `KAREN_CACHE_ROOT`, `KAREN_DV_CHECKPOINT_ROOT`.

## Adam must supply (if missing)

1. Cloudflare account + R2 bucket `karen-nq-history`
2. R2 API token → `KAREN_R2_*` env vars
3. AWS CLI **or** rclone installed on desktop (upload) and laptop (pull)
4. Hetzner (or Fly/AWS) VM per `vm-hetzner.md`
5. SSH keys on laptop for VM monitor/resume

## Resource isolation vs DEV research jobs

- Prefer `--profile min-dev` and rclone `--bwlimit 4M..8M`
- Hashing scripts yield between chunks / sleep between files
- Do not kill or duplicate running supervisor / c4 / overcaution / shadow-dump jobs
- Full `raw-append` only off-peak or heavily throttled
